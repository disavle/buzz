Цифры кофеина, сахара и денег всегда в .rounded и с .monospacedDigit(), чтобы не прыгали при анимации .contentTransition(.numericText()).
Формы и отступы
Карточка секцииRoundedRectangle(cornerRadius: 26)
Карточка в сетке каталогаcornerRadius: 22
Плитка бренда 44 / 52 ptcornerRadius: 12–16

Главная кнопка.borderedProminent, .capsule, 52 pt
Мин. зона нажатия44 × 44 pt
Таб-бар, сегменты, поиск и шит не рисуем руками: TabView, Picker(.segmented), .searchable и .sheet на iOS 26 сами дают стекло (Liquid Glass) и скругления, как на макетах.
Перенос в код
// Core/DesignSystem/Theme.swift — цвета лежат в Assets.xcassets (Any + Dark)
extension Color {
    static let buzzAccent = Color("BuzzAccent")   // кофеин, кольцо, главные кнопки (= AccentColor)
    static let buzzOver   = Color("BuzzOver")     // превышение лимита
    static let buzzSugar  = Color("BuzzSugar")    // сахар
}

extension Font {
    static let buzzHero   = Font.system(size: 52, weight: .bold, design: .rounded).monospacedDigit()
    static let buzzMetric = Font.system(.title, design: .rounded).bold().monospacedDigit()
}

// Фон экранов: .background(Color(.systemGroupedBackground)), карточки: Color(.secondarySystemGroupedBackground)
